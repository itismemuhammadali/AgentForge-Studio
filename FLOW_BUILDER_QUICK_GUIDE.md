# Flow Builder - Quick Start Guide

## Overview
The Flow Builder is a visual tool for creating chatbot conversation flows. You can drag nodes onto a canvas, connect them with arrows, and define the logic of your bot's interactions.

## Getting Started

### Step 1: Open Flow Builder
1. Navigate to "My Bots" section
2. Click on a bot or create a new one
3. Click the "Flow Builder" tab

### Step 2: Choose Your Starting Point
You have three options:
- **Start from Scratch**: Begin with an empty canvas and a Start node
- **Restaurant Template**: Pre-built flow for restaurant booking
- **Webshop Template**: Pre-built flow for e-commerce
- **Healthcare Template**: Pre-built flow for appointment booking

## Building Your Flow

### Adding Nodes
1. Look at the left sidebar - it shows all available node types
2. Drag any node type onto the canvas
3. The node appears where you dropped it

### Available Node Types
- **Start** (Green) - Entry point of your flow
- **Stop** (Red) - Exit point of your flow
- **Question** (Red) - Ask the user a question
- **Text Message** (Gray) - Send a message to the user
- **AI Node** (Yellow) - Use AI to generate responses
- **API Call** (Black) - Call an external API
- **Logic Switch** (Blue) - Branch based on conditions
- **Handover** (Red) - Transfer to human agent
- **Booking Mode** (Gray) - Enable booking functionality
- **Lead Capture** (Gray) - Capture user information

### Connecting Nodes

#### Method 1: Using the Sidebar Buttons (Recommended)
1. Click on the first node (it gets a blue border)
2. Click on the second node (both now have blue borders)
3. In the sidebar, click "Make Connection"
4. An arrow appears connecting the nodes

#### Method 2: Using Connection Mode
1. Click the "Connect" button in the sidebar
2. Click on the first node
3. Click on the second node
4. Arrow is created automatically

### Modifying Connections

#### To Reverse an Arrow
1. Select the two connected nodes
2. Click "Reverse Arrow" button
3. Arrow now points in the opposite direction

#### To Remove an Arrow
1. Select the two connected nodes
2. Click "Remove Arrow" button
3. Arrow is deleted

### Editing Nodes

#### To Edit a Node's Label or Notes
1. Click the pencil icon on the node
2. Edit the label and/or notes
3. Click "Save"

#### To Delete a Node
1. Click the trash icon on the node, OR
2. Select the node and click "Delete Selected" in the toolbar

## Canvas Controls

### Zooming
- **Zoom In**: Click the + button or scroll up
- **Zoom Out**: Click the - button or scroll down
- **Fit to Screen**: Click the fit button to reset zoom

### Panning
- Click and drag on empty canvas to move around

### Fullscreen Mode
- Click the fullscreen button to expand the canvas
- The sidebar stays visible in fullscreen mode
- Click again to exit fullscreen

## Tips & Tricks

### Multi-Select
- Click multiple nodes to select them all
- Selected nodes have blue borders
- Use this to create connections between any two nodes

### Templates
- Templates are great starting points
- You can modify them by adding, removing, or editing nodes
- All templates follow best practices for conversation design

### Best Practices
1. Always start with a "Start" node
2. Always end with a "Stop" node
3. Use "Question" nodes to branch conversations
4. Use "Text Message" for static responses
5. Use "AI Node" for dynamic responses
6. Keep flows simple and logical
7. Test your flow before deploying

## Troubleshooting

### Nodes Won't Connect
- Make sure you have exactly 2 nodes selected
- Check that the "Make Connection" button appears in the sidebar
- Try clicking the nodes again to ensure they're selected

### Arrows Not Visible
- Zoom in to see arrows better
- Check that nodes are actually connected (try selecting them again)
- Arrows are blue curved lines with arrow heads

### Can't Drag Nodes
- Make sure you're not in connection mode
- Try clicking the node first to select it
- Then click and hold to drag

### Selection Issues
- Click on empty canvas to deselect all nodes
- Click individual nodes to select them
- Multiple nodes can be selected at once
